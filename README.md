# C and C++ Programs

Beginner programs in C and C++ that I wrote while learning the basics: input/output, operators, loops, conditions and functions.

## Programs

**C**
- `Calculator.c`: calculator for basic arithmetic
- `Factorial of a Number.c`
- `Fibonacci Series up to N Terms.c`
- `decimal to binary.c`
- `meters to km.c`
- `Sum of 2 No's.c`, `Sum of 3 no's.c`

**C++**
- `Number Guessing Game.cpp`: guess a random number from 1 to 100, with hints and an attempt counter
- `Simple Calculator.cpp`
- `Arithmetic Operators.cpp`
- `find LCM of two numbers.cpp`
- `Greeting with Name.cpp`

`Test.c` and `Test.cpp` are Hello World programs used to check the compiler setup.

## Compiling and running

With GCC / G++:

```bash
gcc "Factorial of a Number.c" -o factorial
./factorial

g++ "Number Guessing Game.cpp" -o game
./game
```
